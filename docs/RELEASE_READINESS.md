# Legacy Codekeeper release delivery

The legacy Codekeeper release automation has been retired as part of the
migration to Rivet. Its release-preparation and tag-triggered publication
workflows are no longer present, and this document is retained only as a
historical pointer.

No replacement Rivet publication workflow is defined here. The Rivet package is
not yet publication-ready; use [Rivet migration authority](RIVET_GH_AW_MIGRATION.md)
and [Rivet repair qualification](RIVET_REPAIR_QUALIFICATION.md) for the current
delivery boundaries and evidence requirements.
